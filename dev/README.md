# `dev/` — internal working notes

Working notes for *developing* T3Toolbox: handoffs, status, and plans. This is **not**
user documentation (that lives in `docs/`), **not** part of the shipped package, and
**not** rendered into the doc site.

- **Top level** — current/active notes. Default to one living `HANDOFF.md`; keep more than
  one (e.g. per active thread) when work is genuinely interleaved.
- **`archive/`** — dated, superseded notes, preserved for the record and swept here
  periodically. A little confined clutter at the top level is fine as long as it gets
  swept down here.

**Routing rule** (where new writing goes): user-facing design rationale → `docs/`;
process / status / plans → here; research experiments + findings → a separate
research repo (maintainer-local).
