# `slices/` — per-slice implementation handoffs and reviews

One implementer agent and one independent reviewer agent per slice of `../../riemannian_newton_curvature_impl_plan.md`
(plan §H). `S<slice>_handoff.md` is the implementer's record (files, measurements, plan-vs-doc conflicts, judgment
calls); `S<slice>_review.md` is the reviewer's findings and verdict. A slice is committed only on `VERDICT: APPROVE`.
Deferred items from reviews are collected in `DEFERRED.md`.
