## Inconsistencies found

1. **"Masks are prefix" overstated.** `backend/ut3_masking.py` says "Masks are boolean prefix vectors" and
   `uniform_svd_prefix_orthogonalization.md` says the layer "represents per-stack ranks as prefix masks [0, rank)".
   But `uniform_rank_masks_rationale.md`, `weighted_internals.md`, `uniform_masks_vs_ranks.md` and
   `padded_frame_internals.md` ("Nothing assumes junk-last on input") make prefix only the canonical form: masks go
   gappy under `+`/`×`. The glossary should define both forms.
2. **Traced masks.** The house rule is "masks are HOST, never traced" (`signature_style.md`, `common.prefix_mask`),
   and `pad_safe_pinned_completion` requires HOST masks. Yet `linalg.pad_safe_svd` says its masks "are runtime data of
   static length: under jax they may be traced". A different contract inside one module; the glossary entry for
   "rank mask" should note the exception.
3. **Stale wording in `common.require_concrete_masks`**: "output `aux_data` (identity-hashed, never-inspected)". The
   holders have been value-hashed since the `uniform_pytree_composition.md` decision.
4. **Frame core symbols.** `(U, O, L, R)` in `curvature_internals.md`; `(U, O, P, Q)` in `backend/optimizers.py`
   `LocalModel.frame` and in `batching_internals.md`'s letter list; `(up, down, left, right)` in `padded_frames.py`;
   `up_tucker_cores, down_tt_cores, left_tt_cores, right_tt_cores` in `fv_conversions.py`/`tv_operations.py`; and the
   `update` letters `U, O, L, R` where `O` means the down store. Variations are `(V, H)`, `(tucker_variations,
   tt_variations)`, `(tucker_var, tt_var)` (`optimizers.py`) or `(dU, dG)`.
5. **The base-point cores.** `padded_frame_internals.md` calls `left[d-1]` and `right[0]` the "carriers";
   `frame_variations.md` calls the extras `Ld` and `R0` while numbering cores `L0…L(d-1)`, so `Ld` does not exist as a
   core (off by one); `weighted_internals.md` says "the frame's `d+1`-th left/right cores". Three names, two indexings.
6. **`W` name.** "probe stack" (`batching_and_stacking.md`, `naming_conventions.md`, `contractions.py`) vs "sample
   stack" (`fitting.py` `SamplingKind`, `sampling_derivatives.py` STACKING comment).
7. **`K` as derivative order.** `sampling_derivatives.py`'s module comment writes `t = 0, 1, ..., K`, which the
   2026-08-24 ruling in `naming_conventions.md` forbids (`K` is the tangent stack; the order is `order`, `m` in the
   math note).
8. **Dead name in a comment.** `sampling_derivatives.py` says `assemble_z_jets` lifts "via `tWCi_Cio_to_tWCo`", a
   named-contraction function deleted on 2026-07-17.
9. **"Named contractions".** In the docs this means the retired ~104 enumerated functions
   (`contractions.py`, `batching_internals.md`). Nick's library-conversion requirements use "named contractions" for
   grouped `contract` strings. The glossary must pick one meaning or define both.
10. **"Companion" has five uses.** `SharedFrameData` ("the companion"); the curvature pytrees `LiftFactors`,
    `ManifoldCurvatureData`, `CurvatureState` ("the companion pytree rule"; `CurvatureState` "the exact-mode
    companion"); `geom_aux` ("per-frame companion"); the dotted-jet layout ("companion arrays", I-10); and doc
    cross-references ("Companion: ...").
11. **"Transport".** Vector transport (`MANIFOLD.transport` = `project_ambient` onto a new frame) vs store transport in
    the alignment step (an un-updated store re-expressed in new coordinates).
12. **"Store".** Rank store (up/down/left/right) vs "store vs recompute" / "a store variant" (memory trade-offs in
    `fitting_internals.md`, `curvature_internals.md`).
13. **"Slot".** A rank index (real or junk slot, slot-indexed seeds) vs "flat slots" (I-12), a slot at maximal rank
    where the curvature vanishes.
14. **"Block".** Batch blocks `C`/`W`/`K`; A-block/P-block; the "real block" of a padded matrix; the diagonal blocks
    of the block-sum oracle; `block_sumsq`'s (mode, order) blocks.
15. **"Group".** A sharing group vs a `contract` group (an uppercase letter standing for several axes).
16. **"Sweep".** Orthogonalization sweep, T3-SVD sweep, frame sweep (the `sweep` field of edge variables),
    `rank_adjustment_sweep`, and test sweeps (`oracle_sweeps/`, the sharding sweep, "sweep many directions").
17. **"Residual".** Fitting residual `r = S(x) − data`; checker residuals (`orthogonality_residual`,
    `gauge_residual`, `sharing_residual`); the CG residual `rs`.
18. **"Reference".** The g0 reference; the ragged layer as the trusted reference for uniform; `_trs` reference twins;
    the start's "convention reference" (T5).
19. **"Padded/padding".** Uniform junk slots; a zero-padded rank increase (real slots with zero content, "padded
    restart"); the padded frame (old frame plus completion); packed vectors "zero-padded to the common width N".
20. **"Completion".** The P-block of a padded frame; the orthonormal vectors an SVD supplies at zero-σ slots;
    `pinned_completion`'s output.
21. **"Lift".** `tv_corewise_lift` (exact Hessian) vs "passive-broadcast Tucker lifts" (`batching_internals.md`) vs
    "lift each order through the Tucker cores" (`sampling_derivatives.py`) vs the misfit gradient's "ambient lift"
    (`deferred_and_rejected.md`).
22. **"Direction".** Sample perturbation `pp` (jets), core direction `θ̂` (two-hole), a padded frame's "new
    directions".
23. **Four spellings of "unshared".** Per-mode `sharing` labels with `None`; canonical `groups` with singletons
    (`validate_sharing`); `()` (`canonical_groups`, the geometry field); and a `None` sentinel open-coded at seven
    sites in `ranks.py`, `t3_svd.py`, `ut3_svd.py` (acknowledged in `deferred_and_rejected.md`).
24. **`newton_cg` `g0_reference` signature comment** lists `None | 'zero' | 'warm_start'`; the docstring and
    `_check_g0_reference` also accept `'cone'`.
25. **Wrong test file.** `curvature_internals.md` F35/F36 credits "the import DAG is acyclic" to
    `tests/test_contractions_interpreter.py`; the check is in `tests/test_import_graph.py`.
26. **`xwhile` dispatch.** `scan_body_principles.md` says `get_backend` dispatches `xwhile` to `lax.while_loop`.
    `xwhile` is not returned by `get_backend`; it is a separate `common` function that uses `lax.while_loop` only with
    `use_jit=True` and a jax state, and runs a Python loop for eager jax.
27. **Gauge condition notation.** `Uᵢᵀ Vᵢ = 0` (`frame_variations.md`), `U_i V_i^T = 0`
    (`tv_orthogonal_gauge_projection`), "gauge grams `U^T V`" (`tv_gauge_residual`). The row/column convention is not
    stated.
28. **Direction words for edge variables.** `compute_mu` is documented as "leftward edge variables" and `compute_nu`
    as "rightward", while `mu` is accumulated left to right through the left cores. The words name the side, not the
    travel direction; the zippers use `left_to_right`. A reader can take them the wrong way.
29. **Packedness strictness vs mirror.** `uniform_polymorphism.md`: a sampling op is strict about operand types and a
    mismatch "is a structural error, never a silent auto-pack". `uniform_equivalence_contract.md` and
    `ut3_operations.pack_if_ragged`: uniform ops accept ragged vectors and mirror packedness. Probably backend cores
    vs wrappers, but neither page says so.
30. **`GeometryOps`.** `backend/regularization.py` says each method "receives a `GeometryOps`"; `geometry.py`
    calls `GeometryOps` "the previous ... record-of-lambdas". The current classes are `ManifoldGeometryOps` etc.
    and the protocol is `optimizers.Geometry`.
31. **One `LocalModel` name for two classes** (backend `optimizers.LocalModel`, frontend `fitting.LocalModel`).
    Deliberate and documented, but the glossary should say which one it means.
32. **Down core name.** The store is "down" and the symbol `O` ("down/outer core"), but the data name is
    `down_tt_cores`, which reads as a TT core family.
33. **Junk synonyms.** "junk" (`padded_frame_internals.md`, `linalg.py`), "garbage" (equivalence contract, testing),
    "padding" and "don't-care" all name the same slots. Worth one canonical term in the glossary.
